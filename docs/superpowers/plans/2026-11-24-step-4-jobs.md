# Step 4: Jobs & Opportunities Experience Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the complete Jobs & Opportunities subsystem, including the Interactive Job Board (`/jobs`) with multi-facet reactive filtering, dynamic Job Detail View (`/jobs/:id`), enriched job data models, and direct resume submission pathways.

**Architecture:** Reactive Angular 19+ architecture using standalone components, signal route input binding (`id = input.required<string>()`), query parameter synchronization (`ActivatedRoute`), shared UI primitives (`ButtonComponent`, `TiltCardDirective`, `RevealDirective`), and strict Amber Isolation for candidate conversion.

**Tech Stack:** Angular 19+ (Signals, Standalone), Tailwind CSS, Vitest / `@angular/build:unit-test`.

**Spec:** `docs/superpowers/specs/2026-11-24-step-4-jobs-design.md`

## Global Constraints

- **Strict Amber Isolation:** `#F59E0B` (`variant="amber-cta"`, `.glow-amber`) is reserved **EXCLUSIVELY** for the candidate conversion "Submit Your Resume" button.
- **Mandatory Honest Disclosure:** All job listings on the catalog and detail pages are illustrative representations of client requirements and must carry `<span class="illustrative-badge">Illustrative listing</span>` and the disclaimer banner.
- **US Terminology:** "Submit Your Resume" (never "CV"), "Candidate", "Engineering Recruiting Firm", "Apply Now", "Compensation".
- **Zero Misleading Claims:** No claims of US physical offices, visa sponsorship, or direct client partnerships.
- **TDD:** Write failing tests first, watch them fail, implement minimal code to pass, refactor.
- **Production Build:** `npm run build` must succeed with zero errors.

export class JobsComponent implements OnInit {
  private route = inject(ActivatedRoute);

  readonly allJobs = FEATURED_JOBS;
  readonly disciplines = DISCIPLINES;

  readonly searchQuery = signal<string>('');
  readonly locationQuery = signal<string>('');
  readonly selectedDiscipline = signal<string>('all');

  ngOnInit(): void {
    this.route.queryParams.subscribe(params => {
      if (params['q']) this.searchQuery.set(params['q']);
      if (params['location']) this.locationQuery.set(params['location']);
      if (params['discipline']) this.selectedDiscipline.set(params['discipline']);
    });
  }

  onSearchInput(event: Event): void {
    const input = event.target as HTMLInputElement;
    this.searchQuery.set(input.value);
  }

  onLocationInput(event: Event): void {
    const input = event.target as HTMLInputElement;
    this.locationQuery.set(input.value);
  }

  setDiscipline(slug: string): void {
    this.selectedDiscipline.set(slug);
  }

  resetFilters(): void {
    this.searchQuery.set('');
    this.locationQuery.set('');
    this.selectedDiscipline.set('all');
  }

  hasActiveFilters = computed(() => {
    return this.searchQuery().trim().length > 0 ||
           this.locationQuery().trim().length > 0 ||
           this.selectedDiscipline() !== 'all';
  });

  filteredJobs = computed(() => {
    const q = this.searchQuery().trim().toLowerCase();
    const loc = this.locationQuery().trim().toLowerCase();
    const disc = this.selectedDiscipline();

    return this.allJobs.filter(job => {
      const matchesDiscipline = disc === 'all' || job.disciplineSlug === disc;
      const matchesLocation = !loc || job.location.toLowerCase().includes(loc);
      const matchesSearch = !q ||
        job.title.toLowerCase().includes(q) ||
        job.description.toLowerCase().includes(q) ||
        job.tags.some(tag => tag.toLowerCase().includes(q));

      return matchesDiscipline && matchesLocation && matchesSearch;
    });
  });
}
